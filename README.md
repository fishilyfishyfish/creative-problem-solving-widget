# 급식·시간표 위젯

창의적문제해결연습 과제. 안드로이드 홈 화면 위젯 하나로 그날 시간표와 급식을 같이 본다.

## 해결하려는 문제

- 아침마다 시간표와 급식을 따로 확인해야 한다
- 지금 몇 교시인지, 다음 수업이 뭔지 한눈에 안 보인다
- 알레르기가 있으면 급식표에서 알레르기 번호를 하나하나 찾아봐야 한다
- 저녁에 다음 날 시간표를 보려면 또 따로 찾아야 한다

## 위젯

| 위치 | 내용 |
|---|---|
| 왼쪽 위 | 요일 |
| 왼쪽 | 교시마다 과목과 교실. **지금** 교시는 빨강, **다음** 교시는 파랑 |
| 오른쪽 | 급식 메뉴. 체크한 알레르기 번호가 든 메뉴는 노랑 |

- 식사 시간에는 "급식" 제목이 빨강(지금)으로 바뀐다
- 급식 칸은 시간에 맞는 끼니를 보여준다. 중식 시간이 지나면 석식으로 바뀐다
- 하교 시간이 지나면 다음 등교일(금요일이면 월요일)의 시간표와 급식으로 바뀐다
- 비워둔 교시는 위젯에 나오지 않는다

## 앱 화면

한 화면에서 아래를 차례로 입력한다. 바꾸면 바로 저장되고 위젯에 반영된다.

1. **시간표**: 월~금 표. 칸을 누르면 과목과 교실 입력. 왼쪽 칸을 누르면 교시 시각 입력 (모든 요일 공통, 최대 9교시)
2. **하교 시간**: 요일마다 따로
3. **식사 시간**: 조식·중식·석식 시간. 없는 끼니는 "없음" 체크
4. **알레르기**: 19종 알레르기 번호 체크
5. **학교 이름**: 검색해서 선택
6. **교육청 인증키**: 나이스 인증키 붙여넣기

## 설치

1. 저장소의 **Actions** 탭 → 가장 최근의 초록색 실행 → 아래쪽 **Artifacts**에서 `app-debug` 다운로드
2. zip을 풀면 `app-debug.apk`가 나옴. 폰으로 옮겨서 설치
3. 설치할 때 "출처를 알 수 없는 앱" 허용이 필요함
4. 홈 화면을 길게 눌러 위젯 목록에서 **급식·시간표** 추가

코드를 `main`에 푸시할 때마다 자동으로 새 APK가 빌드된다.

## 교육청 인증키

[나이스 교육정보 개방 포털](https://open.neis.go.kr)에서 회원가입 후 무료로 발급받는다. 키가 없으면 한 번에 받을 수 있는 양이 적어서 급식이 일부만 보일 수 있다.

- **앱에서 입력 (추천)**: 맨 아래 인증키 칸에 붙여넣기
- **빌드에 포함**: 저장소 Settings → Secrets and variables → Actions → `NEIS_API_KEY` 이름으로 추가

저장소가 공개 상태면 두 번째 방법은 피하는 게 낫다. Actions에서 만든 APK는 GitHub에 로그인한 사람이면 받을 수 있고, APK 안의 키는 꺼낼 수 있다.

## 동작 방식

- 위젯은 교시·식사 시작과 끝, 하교 시간, 자정마다 다시 그려진다
- 급식은 6시간마다, 그리고 필요한 끼니가 없을 때 받아와서 폰에 저장해둔다. 위젯은 저장된 값만 읽는다
- 화면이 꺼져 있을 때는 깨우지 않고, 다음에 화면이 켜질 때 갱신한다

## 구조

```
app/src/main/java/io/github/fishilyfishyfish/cpswidget/
├── logic/      지금·다음 교시 판정, 끼니 고르기, 급식 파싱, 위젯 내용 만들기 (단위 테스트 있음)
├── data/       설정·급식 저장, 나이스 API 호출
├── widget/     위젯 화면 (Glance)
├── schedule/   알람, 백그라운드 급식 갱신
└── ui/         앱 화면 (Jetpack Compose)
```

`app/src/test`의 단위 테스트는 빌드할 때마다 같이 돌아간다.

## 한계

- 시간표는 직접 입력이라 당일 교체는 앱에서 손으로 바꿔야 한다
- 학교가 급식표에 알레르기 번호를 빠뜨리면 강조되지 않는다. 위젯만 믿지 말고 급식표도 확인할 것
- 공휴일·방학에도 입력한 시간표가 그대로 보인다 (급식은 "급식 정보 없음")
