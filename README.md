# 급식·시간표 위젯

창의적문제해결연습 과제. 안드로이드 홈 화면 위젯 하나로 오늘 시간표와 점심 메뉴를 같이 본다.

## 해결하려는 문제

- 아침마다 시간표와 급식을 따로 확인해야 한다
- 알레르기가 있으면 급식표에서 알레르기 번호를 하나하나 찾아봐야 한다
- 저녁에 다음 날 시간표를 보려면 또 따로 찾아야 한다

## 기능

| 기능 | 설명 |
|---|---|
| 시간표 | 요일별로 직접 입력. 비워둔 교시는 표시 안 함 |
| 현재 교시 강조 | 교시별 시작·끝 시각을 입력해두면 수업 중인 교시를 진하게, 쉬는 시간에는 다음 교시를 연하게 강조 |
| 하교 후 전환 | 요일별 하교 시간이 지나면 다음 등교일(금요일이면 월요일)의 시간표·급식으로 바뀜 |
| 점심 메뉴 | 나이스 교육정보 개방 포털에서 받아옴 |
| 알레르기 강조 | 19종 알레르기 번호 중 체크한 것, 또는 직접 적은 재료가 든 메뉴를 빨갛게 표시 |

## 설치

1. 저장소의 **Actions** 탭 → 가장 최근의 초록색 실행 → 아래쪽 **Artifacts**에서 `app-debug` 다운로드
2. zip을 풀면 `app-debug.apk`가 나옴. 폰으로 옮겨서 설치
3. 설치할 때 "출처를 알 수 없는 앱" 허용이 필요함

코드를 `main`에 푸시할 때마다 자동으로 새 APK가 빌드된다.

## 처음 설정

1. 앱을 연다
2. **학교** 탭: 학교 이름으로 검색해서 선택
3. **시간표** 탭: 요일마다 과목과 하교 시간 입력
4. **교시 시간** 탭: 학교 일과표에 맞게 교시별 시작·끝 시각 수정
5. **알레르기** 탭: 해당하는 번호 체크, 필요하면 재료 직접 추가
6. 오른쪽 위 **저장**
7. 홈 화면을 길게 눌러 위젯 목록에서 **급식·시간표** 추가

## 나이스 인증키

[나이스 교육정보 개방 포털](https://open.neis.go.kr)에서 회원가입 후 무료로 발급받는다. 넣는 방법은 둘 중 하나.

- **앱에서 입력 (추천)**: 학교 탭의 인증키 칸에 붙여넣고 저장
- **빌드에 포함**: 저장소 Settings → Secrets and variables → Actions → `NEIS_API_KEY` 이름으로 추가

저장소가 공개 상태면 두 번째 방법은 피하는 게 낫다. Actions에서 만든 APK는 GitHub에 로그인한 사람이면 받을 수 있고, APK 안의 키는 꺼낼 수 있다.

## 동작 방식

- 위젯은 교시 시작·끝, 하교 시간, 자정마다 다시 그려진다 (정확한 알람 사용)
- 급식은 6시간마다, 그리고 필요한 날짜의 메뉴가 없을 때 받아와서 폰에 저장해둔다. 위젯은 저장된 값만 읽는다
- 화면이 꺼져 있을 때는 깨우지 않고, 다음에 화면이 켜질 때 갱신한다

## 구조

```
app/src/main/java/io/github/fishilyfishyfish/cpswidget/
├── logic/      시간표·교시 판정, 급식 파싱, 위젯 내용 만들기 (안드로이드 의존성 없음, 단위 테스트 있음)
├── data/       설정·급식 저장, 나이스 API 호출
├── widget/     Glance 위젯 화면
├── schedule/   알람, 백그라운드 급식 갱신
└── ui/         설정 화면 (Jetpack Compose)
```

`app/src/test`의 단위 테스트는 빌드할 때마다 같이 돌아간다.

## 한계

- 시간표는 직접 입력이라 당일 교체는 앱에서 손으로 바꿔야 한다
- 학교가 급식표에 알레르기 번호를 빠뜨리면 강조되지 않는다. 위젯만 믿지 말고 급식표도 확인할 것
- 공휴일·방학에도 입력한 시간표가 그대로 보인다 (급식은 "급식 정보 없음"으로 표시)
